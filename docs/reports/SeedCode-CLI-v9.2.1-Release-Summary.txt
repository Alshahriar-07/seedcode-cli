WHAT CHANGED
------------
v9.2.1 completes the agent tool surface the contract promises. The v9.2.0
execution loop was audited first and was found to be genuinely working:
native tool calling with a text-protocol fallback, tool results fed back to
the model, real file/shell execution, model-exposed thinking, and an
evidence-verified task graph (813 tests passing before the change).

The real gap was the tool *surface*: several tool names the agent contract
requires were never registered, so a model asking for run_tests, copy_file or
get_command_output was told the tool did not exist. v9.2.1 adds them for real,
reusing existing implementations where one already existed.

NEW TOOLS (real execution, verified on disk)
  create_file        Creates a NEW file; refuses to clobber an existing file
  copy_file          Byte-verified copy; refuses an existing destination
  run_tests          Detects pytest / npm / cargo / go; returns the real result
  get_command_output Returns captured output of a command this session ran
  check_exit_code    Returns the real exit code (or says it is still running)
  inspect_process    Lists session commands with state, exit code and age
  list_directory     Exact alias of list_dir
  search_files       Exact alias of find_files
  search_content     Exact alias of search_text

OTHER CHANGES
  * Command registry: every executed command is recorded with its real output
    and exit status; run_command gained background execution tracked to exit.
  * ToolResult.exit_code carries real process status instead of parsing text.
  * Cloud reasoning: OpenAI-compatible providers relay reasoning /
    reasoning_content / reasoning_details deltas as ThinkingDelta, so the
    thinking panel shows real reasoning on those backends too. Models without
    a reasoning channel produce none.
  * Version 9.2.1 synchronised across package, wheel/sdist, npm launcher,
    installers and documentation.
  * LICENSE flattened to plain text (no ASCII-art rules or symbol bullets);
    the installer's license page and every package carry it.
  * install.ps1 now creates Desktop + Start Menu shortcuts (was missing),
    the Setup installer's Desktop icon is checked by default, and pip
    installs create them on first launch; seedcode --install-shortcuts
    recreates them.
