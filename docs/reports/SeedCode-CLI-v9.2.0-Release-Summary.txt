IMPLEMENTED IMPROVEMENTS
--------------------------------------------------------------------------------
* Single unified coding agent: one engine, one turn lifecycle
  (task analysis -> workspace inspection -> plan -> TODO -> tool execution ->
  verification -> final report). Mode switching removed.
* Right-side task plan panel: live TODO rendering from real orchestrator events
  (o pending / . in progress / v done / x failed / r retrying), N/M progress,
  "All tasks completed" only when every task is verified.
* Model thinking panel: bounded, collapsible, auto-scroll with manual-scroll
  override. Shows ONLY ThinkingDelta content the model itself exposes
  (Ollama thinking capability detected via GET /api/show). Never synthesized.
* Ollama improvements: capability-aware think flag, ThinkingDelta emission and
  relay, streaming robustness (partial/malformed chunks, empty responses,
  timeouts), auto-start without duplicate servers, provider never silently
  switched.
* Completion verification: files re-read after write, real exit codes parsed,
  real test results, COMPLETED / PARTIALLY COMPLETED / FAILED / CANCELLED.
* Real activity logging: tool name, path, command, status, exit code, duration,
  diff previews; no AI > prefix; no fake logs.

FIXED ISSUES
--------------------------------------------------------------------------------
* NameError: name 'active_workspace' is not defined
* ImportError: AgentEngine entry-point drift
* Ollama thinking stream dropped in the loop; think flag never requested

* False completion reports (evidence-based verification now required)
* TUI preferred_height signature drift vs prompt_toolkit 3.0.16 (4-arg call)
