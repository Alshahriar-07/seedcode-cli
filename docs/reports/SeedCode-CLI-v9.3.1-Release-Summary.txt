-----------------------
Startup crash reported as:
  NameError: name 'ensure_workspace' is not defined

The workspace initializer was never missing — it lives in
seedcode/workspace.py. seedcode/cli.py referenced it (and terminal state)
without importing either. main() now imports:
  * ensure_workspace  (seedcode.workspace)
  * detect_terminal   (seedcode.utils.terminal_env)
and takes one terminal snapshot used for both the plain-mode and TUI decisions.
No stub function was added; workspace selection behaviour is unchanged.
