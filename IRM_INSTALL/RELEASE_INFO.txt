WHAT'S IN THIS RELEASE
----------------------
The v7.2.5 release artifacts:
  - Windows portable executable (x64)
  - Windows Setup installer (x64)
  - Python wheel (any OS)
  - Python sdist (any OS)
  - SHA256SUMS.txt checksum file covering all of the above

Primary command after any install method:  seedcode
Developer fallback:                        python -m seedcode

INSTALLATION METHODS
--------------------

1) Windows - remote PowerShell installer (recommended on Windows)

     irm https://seedcode-cli.vercel.app/install.ps1 | iex

   Downloads the official SeedCode-CLI-7.2.5-windows-x64.exe from GitHub
   Releases, verifies its SHA-256 against the release's SHA256SUMS.txt
   (cross-checked against a pinned digest built into the installer; a
   mismatch aborts, verification is never bypassed), installs per-user to
   %LOCALAPPDATA%\Programs\SeedCode, adds that directory to the user PATH,
   and verifies the installed binary reports version 7.2.5. PowerShell 5.1
   and 7+ compatible; ANSI UI with graceful fallback; Ctrl+C safe.

2) Windows - Setup installer

   Download SeedCode-CLI-Setup-7.2.5.exe from
   https://github.com/Alshahriar-07/seedcode-cli/releases and run it.
   Installs per-user with a Start Menu shortcut and adds the install
   directory to the user PATH so `seedcode` works in new terminals.
   Preserves configuration during upgrades (user config lives in the
   Seed Code config directory, not the install directory).

3) Windows - portable executable

   Download SeedCode-CLI-7.2.5-windows-x64.exe from the releases page and
   run it directly. No installation, no PATH changes; `seedcode --version`
   reports 7.2.5. For a persistent `seedcode` command, use method 1 or 2.

4) Linux / macOS - remote shell installer

     curl -fsSL https://seedcode-cli.vercel.app/install.sh | bash

   Downloads the official seedcode_cli-7.2.5-py3-none-any.whl from GitHub
   Releases, verifies its SHA-256 against the release's SHA256SUMS.txt
   (cross-checked against a pinned digest built into the installer; a
   mismatch aborts, verification is never bypassed), installs with pipx
   when available (otherwise pip --user, with PEP 668 handling), creates a
   `seedcode` shim in ~/.local/bin, and verifies the installed binary
   reports 7.2.5. Clean ANSI UI with ASCII fallback; Ctrl+C safe.

5) Any OS - pip

     pip install seedcode-cli

   Then run:

     seedcode          (primary command)
     python -m seedcode   (developer fallback)

   First launch initializes the per-user configuration in the Seed Code
   config directory (never inside site-packages), shows provider/model
   status, and prompts for an API key if none is configured. The wheel
   requires Python 3.10+.

6) Node.js launcher (npm)

     npm install -g @alshahriar-07/seedcode-cli

   Thin wrapper that downloads the official release binary for your
   platform on first run and execs it.

UPGRADE SAFETY
--------------
Upgrades preserve user configuration and provider/API settings. The Windows
installers upgrade in place; configuration lives in the Seed Code config
directory and is never deleted by an installer.

CHECKSUMS
---------
Every release artifact has a SHA-256 entry in SHA256SUMS.txt:

  cd dist/release/7.2.5
  sha256sum -c SHA256SUMS.txt          # Linux/macOS
  Get-FileHash <file> -Algorithm SHA256  # Windows

Both remote installers verify before installing: they read the release's
SHA256SUMS.txt as the authoritative expected value, cross-check it against a
digest pinned in the installer (verified against the actual published
artifacts), and abort on any mismatch. If the release checksum file is
unreachable, the pinned digest is used as the expected value and the
installer says so. Verification is never bypassed.
